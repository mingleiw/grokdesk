GrokDesk

Flash the Waveshare ESP32-S3-Touch-LCD-4.3B. Chrome or Edge, desktop, USB-C.

The image is bootloader, partition table, and app in one file, written at offset 0.

This browser cannot flash over USB. Use Chrome or Edge on a computer. Web flashing needs a secure page. Open this from GitHub Pages, not a downloaded file.
  1. Plug the board in with a data USB-C cable.
  2. Click Install and pick the serial port (USB JTAG/serial or a similar name).
  3. If no port appears, hold BOOT, tap RESET or replug USB, then release BOOT.
  4. After it reboots, join the Wi-Fi network GrokDesk-Setup and use the captive portal. A flash clears saved Wi-Fi.

Simulator and status stay at the grokdesk site.
